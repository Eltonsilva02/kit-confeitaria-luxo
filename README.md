# Kit Confeitaria de Luxo no Natal 🎄✨

Página de vendas de alta conversão para o **Kit Confeitaria de Luxo no Natal**.
Desenvolvida com foco em **Mobile First**, **alta taxa de conexão (connect rate)**, design sofisticado natalino (verde-esmeralda, vermelho e dourado) e integração de checkout e tracking.

## 🚀 Tecnologias e Recursos
- **HTML5 & CSS3 nativos**: Ultra leve, sem frameworks pesados, garantindo carregamento instantâneo.
- **Imagens WebP Otimizadas**: Redução superior a 95% no peso das artes mantendo 100% da nitidez em telas Retina/mobile.
- **Carrosséis Contínuos**: Trilhos animados via GPU (`translate3d`) com movimento infinito bidirecional sem interrupções.
- **Popup de Oferta & Upgrade**: Modal responsivo com apresentação dos produtos complementares e ancoragem visual de valor.
- **WhatsTrack & Repasse de UTMs**: Script de rastreamento com repasse determinístico de parâmetros UTM para os links de checkout.

## 📦 Estrutura de Arquivos
- `index.html`: Página de vendas principal.
- `assets/`: Imagens e artes digitais otimizadas em formato WebP.
- `whatstrack.html`: Snippet de rastreamento de conversão.
